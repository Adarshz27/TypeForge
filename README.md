⌨️ TypeForge

Learn. Type. Improve.

TypeForge is a modern, interactive typing practice platform designed to help users improve their typing speed, accuracy, keyboard familiarity, and typing confidence.

Unlike a traditional typing-test website, TypeForge combines typing practice with learning. Users type informative passages covering a wide range of topics while developing their typing skills.

---

✨ Features

⚡ Multiple Typing Tests

Practice with different test durations:

- ⏱️ 1 Minute Test
- 🔥 3 Minute Test
- 🏆 5 Minute Test

Each test measures:

- WPM (Words Per Minute)
- Typing accuracy
- Errors
- Characters typed
- Words typed
- Best WPM

🔤 A–Z Typing Practice

Typing passages are designed to expose users to a broad range of English letters, including less frequently used letters such as:

"Q • X • Z • J • K • V"

This helps users become comfortable with the complete alphabet rather than repeatedly typing only common letters.

🧠 Smart Practice

TypeForge provides simple typing tips based on the user's performance.

Examples:

- Focus on accuracy before speed.
- Keep a steady rhythm.
- Avoid looking at the keyboard.
- Relax your hands and shoulders.
- Practice difficult keys regularly.

Future versions can automatically identify weak keys and generate targeted exercises.

🌐 Deploy with GitHub Pages

TypeForge can be deployed for free using GitHub Pages.

Steps

1. Create a GitHub repository.
2. Upload "index.html".
3. Upload "README.md".
4. Open Settings.
5. Select Pages.
6. Choose the main branch.
7. Save.
8. GitHub will generate your website URL.

🎯 Project Goal

The goal of TypeForge is to create a typing platform where users don't simply chase a higher WPM.

Instead:

Learn → Practice → Test → Analyze → Improve

Users should become faster, more accurate, and more confident while learning useful information along the way.
